## Abstract

Find & Lost is an intelligent Lost and Found Management System
designed to simplify the process of reporting, searching, matching,
and recovering lost items.

Traditional lost-and-found systems mainly depend on manual searching,
physical notice boards, and basic keyword matching. These approaches
are time-consuming and may result in low recovery rates.

The proposed system provides smart item categorization and matching
between lost and found reports. It also protects sensitive item
information and supports ownership verification before handover.
Real-time status updates and notifications help users and
administrators efficiently track the complete recovery process.

## Objectives

- Provide an easy platform to report lost items.
- Allow users to register found items.
- Enable intelligent matching of lost and found items.
- Reduce manual searching and administrative effort.
- Protect sensitive item information.
- Support secure ownership verification.
- Provide real-time status tracking.
- Improve the recovery rate of lost items.
- Maintain a proper record of item handovers.
- Reduce fraudulent ownership claims.

## Key Features

## Technologies Used

-Frontend: React.js, HTML5, CSS3, JavaScript

-Backend: Spring Boot (Java), FastAPI (Python), REST APIs

-Database: MySQL (relational data), ChromaDB / FAISS (vector data)

-AI & NLP: Sentence-Transformers / BERT (semantic text matching), LLMs (dynamic ownership verification)

-Dev & Security Tools: Postman (API testing), Semgrep (code security scanning), GitHub Copilot (coding assistant)
